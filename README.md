# 업무 공유 대시보드 (워크보드)

팀(대표 + 직원)이 함께 쓰는 업무 공유 대시보드입니다. NAS에서 정적 파일로 서빙하면 사무실 컴퓨터, 집 컴퓨터, 핸드폰 어디서든 접속할 수 있습니다. 빌드 과정 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

NAS(또는 아무 웹서버)에 이 폴더를 올리거나, 로컬에서 아래 명령으로 실행합니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속. (NAS라면 `http://NAS주소:포트`)

## 화면 구성

- **홈** — 인사말 + KPI 요약(진행중/오늘 마감/기한 초과/발행 대기/완료), 프로젝트 진행률, 오늘의 업무, 팀원별 현황, 콘텐츠 파이프라인, 빠른 작업, 최근 활동
- **업무 보드** — 할 일/진행중/완료 칸반 보드. 드래그 앤 드롭으로 상태 변경, 담당자·우선순위·검색 필터
- **로켓그로스 / 상품 관리 / 마케팅·리뷰** — 프로젝트 탭 (준비중, 기능 로드맵 표시)
- **블로그 글쓰기 / 릴스 / 쇼츠 / 쓰레드** — 콘텐츠 스튜디오 탭 (준비중). 페르소나 기반 글 자동 작성 예정
- **페르소나** — 글쓰기 말투 관리. 기본 4종(전문가형, 직설형, 친근한 이웃형, 스토리텔러형) 제공, 추가/삭제 가능
- **설정** — 준비중

라이트/다크 모드 자동 대응, 모바일 반응형(햄버거 메뉴) 지원.

## 데이터 저장 (중요)

현재 버전은 브라우저 `localStorage`에 저장합니다. **즉, 기기마다 데이터가 따로 저장되어 아직 기기 간 실시간 공유는 되지 않습니다.**

여러 기기에서 같은 데이터를 보려면 NAS에 작은 API 서버(예: Node.js + JSON 파일, Docker 컨테이너)를 붙여야 합니다. 코드의 `load()`/`save()` 함수만 서버 호출로 교체하면 되도록 저장 계층을 분리해 두었습니다. 이것이 다음 구축 단계입니다.

## 다음 단계 로드맵

1. NAS용 경량 API 서버 (데이터 공유) — `load`/`save`를 `fetch`로 교체
2. 프로젝트 탭 실제 기능 (로켓그로스 진행 단계, 리뷰 의뢰 트래킹 등)
3. 블로그/쓰레드 글 자동 작성 (페르소나 연동, AI API 연결)
4. 예약 발행 큐 관리
