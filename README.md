# 업무 공유 대시보드

팀원들이 업무를 등록하고 상태를 공유할 수 있는 칸반형 대시보드입니다. 빌드 과정 없이 브라우저에서 바로 실행되는 정적 웹앱입니다.

## 실행 방법

브라우저에서 `index.html`을 열거나, 로컬 서버로 실행하세요.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 주요 기능

- 업무 등록/수정/삭제 (제목, 담당자, 설명, 우선순위, 마감일)
- 할 일 / 진행중 / 완료 3단 칸반 보드, 드래그 앤 드롭으로 상태 변경
- 담당자, 우선순위, 키워드로 필터링 및 검색
- 전체 업무 수, 상태별 업무 수, 기한 초과 업무 수 요약 통계
- 라이트/다크 모드 자동 대응

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에 저장됩니다. 별도의 백엔드나 데이터베이스가 필요하지 않으며, 브라우저를 초기화하면 데이터가 사라집니다.
