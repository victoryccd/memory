# 업무용 대시보드 (Work Dashboard)

직원이 사무실 컴퓨터에서 접속해 사업별 업무를 단계별로 처리하는 내부 업무 도구입니다.
개인 조회용 대시보드와는 별도로, 실제 작업(예: 자사몰 세팅 > 블로그 콘텐츠 제작)을 진행하고
기록을 남기기 위한 웹앱입니다.

현재 구현된 업무:

- **자사몰 세팅 > 블로그 콘텐츠 제작**: 화자(전문가형/후기형/지식인형/커스텀)와 주제를
  입력하면 Claude API가 블로그 초안을 자동으로 작성합니다. 초안은 검수 후 완료 처리하며,
  최소 4개 이상 작성 진행률을 표시합니다.

다른 사업/업무는 홈 화면에 카드로 추가될 예정이며, `src/lib/projects.ts`에 단계를 등록하면
됩니다.

## 로컬 개발

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 사무실 NAS/서버에 배포하기

직원은 메인 컴퓨터가 아닌 사무실 내 다른 컴퓨터(NAS 등)에서 이 앱에 접속합니다. 같은 사무실
네트워크(LAN)에 있다면 아래처럼 빌드 후 서버를 띄우고, 사무실 내부 IP로 접속하면 됩니다.

```bash
npm install
npm run build

# .env 파일 (또는 쉘 환경변수)에 ANTHROPIC_API_KEY 설정
ANTHROPIC_API_KEY=sk-ant-... PORT=3000 npm run start
```

`npm run start`는 `next start -p 3000 -H 0.0.0.0`으로 실행되어 모든 네트워크 인터페이스에서
접속을 받습니다. 서버를 실행 중인 기기의 사무실 LAN IP(예: `192.168.0.50`)를 확인한 뒤,
직원 컴퓨터에서 `http://192.168.0.50:3000` 으로 접속하면 됩니다.

- 재부팅 후에도 계속 실행되도록 하려면 `pm2`, `systemd`, Docker 등으로 프로세스를 관리하는
  것을 권장합니다.
- 외부(사무실 밖)에서 접속할 필요가 없다면 포트를 공인 IP/라우터에 포워딩하지 않는 것이
  안전합니다.

## 데이터 저장

업무 데이터는 `data/dashboard.db` (SQLite 파일)에 저장됩니다. 서버를 재시작해도 데이터가
유지되며, 별도의 데이터베이스 서버 설치가 필요 없습니다. 이 파일은 정기적으로 백업하는 것을
권장합니다.

## 새 업무 모듈 추가하기

1. `src/lib/projects.ts`의 `PROJECTS` 배열에 사업과 단계를 추가합니다.
2. 각 단계는 `href`가 있으면 클릭 가능한 페이지로 연결되고, 없으면 "준비중"으로 표시됩니다.
3. 블로그 모듈(`src/app/projects/[projectId]/blog`)처럼 `src/app/projects/[projectId]/<모듈>`
   경로에 페이지와 API 라우트를 추가해 새 업무 화면을 구현합니다.
